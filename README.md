# Sophisticated-Backpacks
Sophisticated Backpacks — the ultimate portable storage mod for Minecraft. Click the link and the .jar downloads instantly — no pages, no waiting. Placeable, dyeable, tiered backpacks with dozens of upgrades: Pickup, Magnet, Feeding, Tank, Battery, Crafting, and more. Works with Forge and NeoForge on 1.18.2–1.21.1.
