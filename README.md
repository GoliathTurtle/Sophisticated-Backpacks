## 📖 What Is Sophisticated Backpacks?

**Sophisticated Backpacks** is a comprehensive backpack mod that goes far beyond simple storage. Backpacks can be placed in the world, dyed in different color combinations, upgraded with larger inventories, and enhanced with dozens of functional upgrades.

The mod is designed for **modularity** — you build the backpack that fits your playstyle. Want a mobile food dispenser? Install a Feeding Upgrade. Need automatic ore pickup? Add a Magnet Upgrade. Want to smelt items on the go? Install a Smelting Upgrade. The possibilities are endless.

**Key highlights:**
- ✅ **Placeable backpacks** — Put them in the world and use them like chests
- ✅ **Multiple tiers** — Leather, Copper, Iron, Gold, Diamond, Netherite
- ✅ **Deep upgrade system** — Dozens of functional upgrades
- ✅ **Dyeable** — Two-color combinations (fabric and stitches)
- ✅ **Curios compatibility** — Wear in the Back slot
- ✅ **Highly configurable** — Change capacities, slots, and recipes
- ✅ **Pipe/funnel compatible** — Automate your backpack storage

## ✨ Features

### 🎒 Backpack Tiers
- **Leather** — Starter tier
- **Copper** — 1 upgrade slot (1.18+)
- **Iron** — 2 upgrade slots
- **Gold** — 3 upgrade slots
- **Diamond** — 5 upgrade slots
- **Netherite** — 7 upgrade slots

Each tier increases storage capacity and upgrade slots.

### 🖱️ Backpack Mechanics
- **Open with hotkey** — Default: **B** (rebindable)
- **Place in world** — Shift + Right-click on ground
- **Pick up** — Empty hand + Shift + Right-click, or break it
- **Renders on your back** — When equipped in chest or Curios slot
- **Fluid slots render** — Visual display of stored fluids
- **Loot generation** — Backpacks and upgrades spawn in loot chests
- **Mob backpacks** — Some mobs spawn wearing backpacks (enhanced, drop loot)

### 🔧 Upgrade Categories

#### **Automation Upgrades**
- **Pickup Upgrade** — Routes drops directly into backpack
- **Magnet Upgrade** — Sucks up items within 5 blocks
- **Feeding Upgrade** — Auto-feeds you from backpack food
- **Void Upgrade** — Deletes specified items on pickup
- **Compacting Upgrade** — Auto-crafts compressed blocks (2x2)

#### **Storage Upgrades**
- **Stack Upgrades** — Multiply max stack size (1.5×, 2×, 4×, 8×, 16×, Omega)
- **Inception Upgrade** — Store backpacks inside backpacks (one level deep)
- **Tank Upgrade** — Fluid storage (based on tier)
- **Battery Upgrade** — Energy storage
- **Restock Upgrade** — Pull items from containers
- **Deposit Upgrade** — Push items to containers
- **Refill Upgrade** — Keep inventory items topped up

#### **Utility Upgrades**
- **Crafting Upgrade** — Built-in crafting grid (JEI/REI/EMI compatible)
- **Anvil Upgrade** — Built-in anvil for repairs and renaming
- **Smithing Upgrade** — Built-in smithing table
- **Stonecutter Upgrade** — Built-in stonecutter
- **Smelting Upgrade** — Furnace functionality (also Smoking/Blasting)
- **Jukebox Upgrade** — Play music discs from backpack
- **Toolswapper Upgrade** — Auto-swap to correct tool
- **Everlasting Upgrade** — Indestructible backpack

#### **Advanced Upgrades**
Almost every upgrade has an advanced version with:
- 16 item filter slots
- Match by item, mod ID, tag, NBT, or durability
- More precise control over behavior

### ⚙️ Settings & Configuration
- **Sorting** — By name, count, mod, or tag
- **Search** — By item name or mod ID
- **Slot Memory** — Remember specific slots
- **Keep Tab Open** — Preserve last open tab
- **Shift-Click Behavior** — Configure where items go first
